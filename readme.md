Python Assesment:

City Bike Sharing Network Dashboard
Objective
Create an interactive Python application that fetches data from the City Bike Network API (http://api.citybik.es/v2/networks), processes it, and presents it in a user-friendly, interactive dashboard with reports and visualizations. The application should support filtering, error handling, and provide multiple types of graphical insights, including bar charts, and aggregated data by country.
Requirements
1.
Fetch and Process Data
o
Use the City Bike Network API (http://api.citybik.es/v2/networks) to fetch data on bike-sharing networks worldwide.
o
The data should be processed to extract essential details, including the network name, city, country, station count, and location coordinates (latitude and longitude).
2.
Data Visualization
o
Bar Chart: Display the number of stations for each bike-sharing network using a bar chart (horizontal preferred).
o
Summary Statistics: Provide aggregated data, such as the average number of stations for each country or city and display it in a user-friendly table.
3.
Error Handling
o
Ensure that the application can gracefully handle errors such as failed API requests, missing data, or invalid user input. Provide informative error messages to the user.
4.
Additional Insights
o
Display additional insights, such as:
▪
The total number of networks available.
▪
The country with the highest number of bike-sharing stations.
▪
The network with the largest number of stations.
5.
User Interface
o
Build the user interface.
o
Ensure that the data is presented in a clean and professional layout with clear headings and sections.
6.
Optional Enhancements
o
Include additional visualizations, such as pie charts for the distribution of networks by country.
7.
Expected Deliverables
o
A Python script that fetches, processes, and visualizes the data.
o
A functional dashboard that displays the information.
o
Code that follows good software development practices, such as modularity, proper error handling, and clear documentation.
o
Solution documentation.
Good Luck!
